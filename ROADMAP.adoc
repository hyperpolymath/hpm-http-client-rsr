== v0.1 — One-shot HTTPS client (current)

*Status: done in scaffold; awaiting CI / packaging.*

* [x] RSR layout (src/abi/, ffi/zig/, ABI-FFI-README.md)
* [x] Idris2 ABI: Types + Foreign with %foreign decls and safe wrappers
* [x] Zig FFI: `hpm_http_client_new` / `_free`, `hpm_http_client_request`,
  `hpm_http_response_status` / `_body` / `_free`
* [x] HTTPS via `std.http.Client` + `std.crypto.tls.Client`
* [x] Zig test suite covering: GET round-trip, POST + body, status code
  capture, body size-query, malformed URL handling, null-safety
* [ ] Generated C header `generated/abi/hpm_http_client.h`
* [ ] CI: `zig build test` on every PR
* [ ] First downstream consumer wired (OikosBot AffineScript port)

== v0.2 — Response inspection + streaming

*Status: planned.*

* [ ] Response header lookup (`hpm_http_response_header`)
* [ ] Streaming body reads (for large payloads beyond the 1 MiB ceiling)
* [ ] Configurable max-body cap per client
* [ ] Redirect-following knobs surfaced through the FFI
